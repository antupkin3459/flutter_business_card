## Опис проєкту
Застосунок-візитівка розробника, що складається з одного екрана. Проєкт демонструє базові навички роботи з віджетами Flutter, управління станом за допомогою `StatefulWidget` та стилізації компонентів з використанням `Theme.of(context)`.

### Реалізований функціонал:
1. Відображення аватара (`CircleAvatar`), імені та спеціальності розробника.
2. Список із 4 контактів (телефон, email, локація, GitHub). Віджет картки контакту (`ContactItem`) винесено в окремий файл для перевикористання.
3. Кнопка «Змінити тему» дозволяє динамічно перемикатися між світлим та темним режимами.
4. Стан теми зберігається у `StatefulWidget` (кореневий віджет застосунку).
5. Використано динамічні кольори з `Theme.of(context).colorScheme` замість жорстко заданих кольорів.

## Інструкція із запуску
1. Переконайтеся, що у вас встановлений Flutter SDK та налаштовано середовище розробки (наприклад, Visual Studio для збірки під Windows).
2. Склонуйте цей репозиторій.
3. У терміналі перейдіть у папку проєкту та виконайте команду для завантаження залежностей:
   ```bash
   flutter pub get
   ```
4. Запустіть застосунок за допомогою команди:
   ```bash
   flutter run -d windows
   ```
   *(або просто `flutter run`, якщо використовується емулятор чи реальний пристрій).*

## Труднощі та їх розв'язання
Під час виконання практичної роботи виникли наступні технічні труднощі:
* **Проблема зі шляхами (Кирилиця):** Компілятор C++ (для Windows-збірки) не міг знайти файли та видавав помилки через наявність кириличних символів в імені користувача Windows (`C:\Users\квасдопил\...`). **Рішення:** Flutter SDK та сам проєкт були перенесені в корінь диска (`C:\src\flutter` та `C:\projects\...`), де шлях містить лише латиницю.
* **Налаштування Git:** При першому коміті Git вимагав ідентифікацію. **Рішення:** Налаштовано глобальні змінні `user.name` та `user.email` через `git config`.
* **Синтаксичні помилки при Hot Reload:** При зміні посилання на GitHub була випадково видалена закриваюча лапка, що призвело до помилки `String starting with ' must end with '`. **Рішення:** Уважний дебаггінг коду, відновлення синтаксису та повторне збереження файлу перед рестартом.

## Звіт про Hot Reload / Hot Restart
Під час розробки активно використовувалися функції швидкого оновлення:
* **Hot Reload (r):** Миттєво застосовував зміни у верстці (наприклад, оновлення посилання на GitHub у `ContactItem`) без втрати поточного стану. Застосунок не перезапускався, а інтерфейс оновлювався за долі секунди.
* **Hot Restart (R):** Використовувався у випадках, коли були допущені синтаксичні помилки в коді, що призводили до падіння збірки, і потрібне було повне перезавантаження застосунку після виправлення.
